How to read this chart

Hard Single compares the predicted probability of the chosen option with observed accuracy. Soft compares it with the reference probability assigned to that option. Curves below the diagonal indicate overconfidence; curves above it indicate underconfidence.

Curves use normalized native predictions with a unique highest-probability option. Invalid predictions, grouped outputs, tied maxima and Hard Set tasks are excluded. The shared cohort is fixed by the source evaluation; selecting different curves does not change its membership. Random has no unique top choice and is omitted.

Exact set match uses the top N ranked options, where N is the reference set size; all N must be correct. Boundary ties do not receive a correct match. Accuracy includes all 633 Hard Set tasks, including grouped requests and failed requests.

Top-N balance uses valid native predictions. After normalizing probabilities within the selected top N, balance is 1 − TV(p, Uniform(N)) / (1 − 1/N), averaged across tasks. A value of 100% means equal weight on the selected options; it can be high even when those options are wrong. Hover over a point to see each metric’s denominator.

Introduction

We introduce MMDM (Massive Multitask Decision Making), a benchmark for text-based System-1 Decision Models. Its 5,448 examples span 16 task categories, bringing knowledge and reading comprehension together with agent state tracking, tool and skill selection, option logic, constraint planning, workflow decisions, and rubric-based scoring.

Recent benchmarks evaluate decision models across diverse tasks, yet real-world decisions combine long contexts, large option spaces, and complex logical dependencies that existing benchmarks do not adequately capture together. MMDM brings these challenges into one evaluation through newly constructed tasks and carefully recomposed and rewritten source material.

Each task provides a state, a question, and a candidate list with request-specific names and criteria. Candidate sets range from 2 to 1,024 options, and complete inputs reach 64,817 tokens. The benchmark tests three distinct answer types: a single correct choice, a complete set of correct choices, and a soft target distribution. Dependencies between options, evolving context, rules and exceptions, and competing plans make the relationships among inputs central to the decision.

Evaluation details

Hard accuracy uses every item of the corresponding label type; failed requests count as incorrect. Soft Brier is averaged over each model’s valid, native full-distribution predictions. Hover over a value to see its denominator.

For inputs beyond a model’s context budget, the evaluation retains the question, options, and criteria, and truncates the middle of the state. Large candidate sets use the recorded native or grouped decision protocol.

Open source identifies models with publicly released weights or adapters and inference code; closed source identifies hosted models without a public checkpoint. Sizes follow the reported model or backbone scale in billions of parameters. For mixture-of-experts models, filtering uses total parameters; active parameters are shown separately when reported. Undisclosed sizes remain a separate group.

Random (uniform) reports analytic expected hard accuracy and a uniform probability distribution. Model names link to available model or project pages.

Reading the Pareto frontier

A model is on the frontier when no displayed model with a disclosed size is both no larger and at least as accurate (or no worse in Soft Brier), with a strict improvement in one dimension. The frontier is computed separately for each metric. Lower Soft Brier is better.

MMDM Dataset

MMDM combines source-grounded adaptations, executable task mechanisms, and decisions drawn from real tool and skill contexts. The release covers 62 source identifiers and 80 category–subcategory combinations. Source evidence, task-specific checks, and independent review support the reference answers.

Each example contains a state—the facts, documents, or conversation available to the model—a question describing the decision, and a list of options. Each option has a name describing a possible answer, action, or score level; an optional criterion explains when it applies. Some criteria refer to other options, so the model must reason about their relationships together.

The reference answer takes one of three forms:

  • Hard Single (4,112 examples): exactly one option is correct. The model must identify that option.
  • Hard Set (633 examples): multiple options are definitively correct. The model must recover the complete correct set, such as all actions that satisfy a set of constraints.
  • Soft (703 examples): the reference assigns a probability to every option. The model must predict the full distribution, representing uncertain outcomes or judgments spread across alternatives.

In the 663 scoring examples, options represent numeric values or ordered levels, such as degrees of answer quality or task completion. The reference specifies either one correct level (35 Hard Single examples) or a probability distribution across levels (628 Soft examples).
